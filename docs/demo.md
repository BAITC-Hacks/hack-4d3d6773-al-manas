# Демо за 5 минут

1. **0:00–0:40** — открыть сайт, указать маркировку синтетических данных, объяснить сводные показатели.
2. **0:40–1:40** — выбрать узел, показать потоки, степень и объяснение роли; подчеркнуть ограничения seed и глубины 4.
3. **1:40–2:30** — поиск gid, фильтр роли, раскраска кластеров, просмотр соседей, масштаб и перемещение.
4. **2:30–3:15** — таблица приоритетов и переход к узлу; карточки кластеров и внутренний объём.
5. **3:15–4:15** — загрузить три файла из demo-data, показать граф после пересчёта. Напомнить, что это всё ещё синтетические файлы: сервер не может определить происхождение загруженного файла.
6. **4:15–5:00** — скачать три CSV, показать воспроизводимый CLI и запуск тестов. Объяснить, что роль — гипотеза, не доказательство виновности.
